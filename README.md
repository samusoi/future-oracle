Future Oracle

Future Oracle — прототип системы, которая пытается прогнозировать движение Bitcoin на основе реальных рыночных данных.

/Как запустить/

1. Клонировать репозиторий:

git clone <ССЫЛКА_НА_РЕПОЗИТОРИЙ>
cd future-oracle

2. Создать виртуальное окружение:

python -m venv .venv

3. Активировать его в Windows PowerShell:

.venv\Scripts\Activate.ps1

4. Установить зависимости:

pip install fastapi uvicorn requests jinja2

5. Запустить сервер:

uvicorn app.app:app --reload

6. Открыть в браузере:

http://127.0.0.1:8000


/Тема проекта/

Проект посвящён прогнозированию движения Bitcoin.
Система определяет одно из пяти направлений:

* STRONG_UP
* UP
* NEUTRAL
* DOWN
* STRONG_DOWN

/Источники данных/

Используются два реальных источника:

CoinGecko — цена Bitcoin, изменение цены за 24 часа и торговый объём.
Alternative.me — Fear & Greed Index и его текущая классификация.

/База данных/

Для хранения информации используется SQLite.
В базе есть три основные таблицы:

* `market_data` — полученные рыночные данные;
* `predictions` — созданные прогнозы;
* `prediction_results` — результаты проверки прогнозов.

Вместе с прогнозом сохраняются использованные показатели, score, уверенность, риск и причины принятого решения.

/Как работает алгоритм/

Прогноз рассчитывается из трёх показателей:

Total Score =
Price Score +
Volume Score +
Fear & Greed Score

Price Score оценивает изменение цены за 24 часа.

Volume Score оценивает торговый объём.

Fear & Greed Score учитывает настроение рынка.

Максимальный итоговый score — +65, минимальный — -65.

На основе итогового значения система определяет направление прогноза, уровень уверенности и риск.

/Проверка прогнозов/
Через 60 минут система проверяет старые прогнозы и сравнивает их с фактическим движением цены.
Если направление совпало, прогноз считается CORRECT. Если нет — WRONG.
На основе этих результатов рассчитывается общая точность модели.

/Использование AI/
AI использовался во время разработки для помощи с написанием и исправлением кода, структурой проекта, SQLite и интерфейсом.
Сам прогноз не генерируется нейросетью. Он рассчитывается программой по заданным правилам и реальным данным.

/Важно/
Это учебный прототип для демонстрации логики прогнозирования. Проект не является финансовым советником и не предназначен для реальной торговли или инвестирования.
