# 🔮 Future Oracle

Future Oracle — прототип системы прогнозирования движения Bitcoin на основе реальных рыночных данных.

Система получает данные из нескольких внешних источников, сохраняет их в SQLite, рассчитывает итоговый score по прозрачным правилам и формирует прогноз:

- `STRONG_UP`
- `UP`
- `NEUTRAL`
- `DOWN`
- `STRONG_DOWN`

После истечения заданного горизонта прогноз автоматически сравнивается с фактическим движением цены. Это позволяет проверять точность модели.

> ⚠️ Future Oracle — экспериментальный прототип. Он не является финансовым советником, не подключает реальные деньги и не предназначен для торговли или инвестирования.

---

## 🎯 Цель проекта

Цель проекта — создать понятный прототип "предсказателя будущего", в котором видно:

1. какие реальные данные используются;
2. из каких источников они получены;
3. как данные сохраняются в базе;
4. как данные преобразуются в числовые показатели;
5. как рассчитывается итоговый score;
6. почему система выбрала конкретное направление;
7. насколько уверена модель;
8. какой риск у прогноза;
9. как система определяет ошибочные прогнозы;
10. насколько точными были предыдущие прогнозы.

Главный принцип проекта:

**прогноз не генерируется случайно — он рассчитывается из реальных сохранённых данных по заранее определённым правилам.**
