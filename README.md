# 🔮 Future Oracle

Future Oracle — прототип системы прогнозирования движения Bitcoin на основе реальных рыночных данных.

Система получает данные из нескольких внешних источников, сохраняет их в SQLite, рассчитывает итоговый score по прозрачным правилам и формирует прогноз:

- STRONG_UP
- UP
- NEUTRAL
- DOWN
- STRONG_DOWN

После истечения заданного горизонта прогноз автоматически сравнивается с фактическим движением цены, что позволяет рассчитывать реальную точность модели.

---

## 🎯 Цель проекта

Цель проекта — создать понятный прототип "предсказателя будущего", в котором можно увидеть:

1. какие реальные данные были использованы;
2. как эти данные преобразуются в числовые показатели;
3. как рассчитывается итоговый score;
4. почему система выбрала конкретное направление;
5. насколько уверена модель;
6. какой риск у прогноза;
7. насколько предыдущие прогнозы оказались точными.

Проект не является финансовым советником и не используется для реальной торговли или инвестирования.

---

# 📊 Источники данных

Future Oracle использует два независимых реальных источника.

## 1. CoinGecko

Используется для получения:

- текущей цены Bitcoin;
- изменения цены за 24 часа;
- торгового объёма за 24 часа.

API:

https://api.coingecko.com/api/v3/simple/price

## 2. Alternative.me

Используется для получения:

- Fear & Greed Index;
- классификации настроения рынка.

API:

https://api.alternative.me/fng/

# 🧠 Алгоритм прогнозирования

Модель использует три независимых сигнала:

1. изменение цены Bitcoin;
2. торговый объём;
3. Fear & Greed Index.

Каждый сигнал преобразуется в отдельный score.

Итог:

```text
Total Score =
Price Score +
Volume Score +
Fear & Greed Score
